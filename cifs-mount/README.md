# smb-automount-cifs.sh — автоматическое монтирование SMB-дисков в домене ALT Linux с Kerberos

## 1. Постановка задачи

В организации используется домен на базе ALT Linux с рабочими станциями под управлением MATE (Caja). Существует необходимость автоматического монтирования сетевых SMB-ресурсов (шар) для каждого пользователя домена. Требования к решению:

- **Без хранения паролей** – аутентификация через Kerberos, так как пароли пользователей меняются каждые 42 дня.
- **Удобный доступ** – в файловом менеджере Caja папки должны отображаться с русскими названиями (например, «Диск S», «Дистриб», «Закупки», «Кадры», «Фото», «Видео», «ИАМ», «Сканы»).
- **Отсутствие мусора в «Устройствах»** – точки монтирования не должны появляться в разделе «Устройства» боковой панели Caja.
- **Автоматическое монтирование при входе** – после входа пользователя диски должны быть доступны без дополнительных действий.
- **Гибкость управления** – администратор может добавлять/удалять диски для конкретного пользователя и выполнять полную очистку настроек.
- **Масштабируемость** – решение легко разворачивается на множестве компьютеров без индивидуальной настройки.

## 2. Архитектура решения

### 2.1. Основные компоненты

Скрипт `smb-automount-cifs.sh` — универсальный bash-скрипт, выполняющий:

- **Сканирование пользователей** – автоматически определяет всех пользователей по каталогам `/home/<DOMAIN>/*` и предлагает выбрать целевого пользователя.
- **Полная очистка (`force_cleanup`)** для выбранного пользователя:
  - размонтирует активные точки в `~/.smb_shares/`;
  - удаляет записи из `/etc/fstab`;
  - удаляет симлинки с русскими именами;
  - удаляет файл закладок Caja (`~/.config/gtk-3.0/bookmarks`);
  - удаляет задания cron и записи в `.profile`.
- **Добавление записей в fstab** для каждой выбранной шары с параметрами `sec=krb5,vers=3.0,noauto,users,uid=...,gid=...,cruid=...`.
- **Монтирование** от имени пользователя через `su - user -c "mount ..."` с использованием текущего билета Kerberos.
- **Создание симлинков** с русскими именами (например, `~/Диск S -> ~/.smb_shares/assembly`).
- **Добавление закладок** в Caja.
- **Настройка автозагрузки**:
  - блок в `~/.profile`;
  - cron-задание на монтирование каждые 5 минут;
  - копирование скрипта в `~/.local/bin/`.
- **Установка setuid** на `/sbin/mount.cifs` при первом запуске.

### 2.2. Режимы работы

| Режим | Команда | Описание |
|-------|---------|----------|
| Интерактивный | `./smb-automount-cifs.sh` | Меню выбора пользователя и дисков, выполнение настройки. |
| Автоматический | `./smb-automount-cifs.sh --user username` | Настройка для указанного пользователя без интерактива. |
| Кроновый | `./smb-automount-cifs.sh --cron` | Монтирует все шары из конфига пользователя (без вывода). |

### 2.3. Схема взаимодействия с системой

```text
root запускает скрипт
  ↓
Выбор пользователя
  ↓
force_cleanup()
  ├─ размонтирование ~/.smb_shares/*
  ├─ удаление записей из /etc/fstab
  ├─ удаление симлинков
  ├─ удаление ~/.config/gtk-3.0/bookmarks
  └─ удаление cron и записей в .profile
  ↓
Выбор дисков (1-8 или 9 для всех)
  ↓
Для каждого диска:
  ├─ добавление записи в /etc/fstab (если отсутствует)
  ├─ монтирование через su - user -c "mount /home/<DOMAIN>/user/.smb_shares/share"
  ├─ создание симлинка
  └─ добавление закладки в Caja
  ↓
Настройка автозагрузки
  ↓
Готово
```

## 3. Ключевые технические решения

### 3.1. Использование Kerberos вместо пароля
- **Проблема:** пароли меняются каждые 42 дня, хранить их в конфигах небезопасно.
- **Решение:** аутентификация через Kerberos (`sec=krb5` в fstab). Билет создаётся при входе через PAM.
- **Преимущества:** безопасность, отсутствие необходимости обновлять пароли в конфигах.

### 3.2. Использование скрытой папки ~/.smb_shares
- **Проблема:** монтирование в `/media` или `/mnt` создаёт визуальный шум в «Устройствах».
- **Решение:** монтирование в скрытую подпапку домашнего каталога. Caja не показывает скрытые папки в «Устройствах».
- **Преимущества:** чистота интерфейса, доступ через симлинки.

### 3.3. Setuid на /sbin/mount.cifs
- **Проблема:** обычный пользователь не может выполнять mount без root.
- **Решение:** установка setuid-бита (`chmod u+s /sbin/mount.cifs`).
- **Безопасность:** монтирование разрешено только для точек, явно прописанных в fstab с опцией `users`.

### 3.4. Закладки Caja вместо монтирования в /media
- **Решение:** создаются симлинки в домашней папке, а закладки Caja добавляются на них.
- **Преимущества:** русские имена, быстрый доступ, отсутствие мусора.

### 3.5. Полная очистка при выборе пользователя
- **Решение:** `force_cleanup` удаляет всё, что было создано скриптом для выбранного пользователя.
- **Преимущества:** гарантированно чистое состояние, упрощение отладки.

## 4. Установка и настройка

### 4.1. Требования к системе
- ALT Linux (поддержка systemd, apt/rpm).
- Пакеты: `cifs-utils`, `krb5-workstation`, `caja` (или другой файловый менеджер).
- Права root для установки setuid и записи в `/etc/fstab`.

### 4.2. Установка
```bash
chmod +x smb-automount-cifs.sh
```

### 4.3. Первый запуск
```bash
./smb-automount-cifs.sh
```

Следуйте интерактивным подсказкам.

### 4.4. Настройка переменных
В начале скрипта можно изменить:
- `SERVER_DEFAULT="fileserver.example.com"` – имя SMB-сервера.
- `DOMAIN="EXAMPLE.COM"` – домен.
- Массив `SHARES` – список шар и отображаемых имён.

## 6. Устранение проблем

| Проблема | Причина | Решение |
|----------|---------|---------|
| Закладки не появляются в Caja | Файл `bookmarks` не обновился или Caja не перечитал его | Проверьте файл, перезапустите Caja или перелогиньтесь |
| `mount error(13): Permission denied` | Отсутствует билет Kerberos или истёк | Проверьте `klist`, выполните `kinit` |
| Симлинки не создаются | Существует каталог с таким же именем | Удалите пустой каталог или переместите содержимое |
| `mount: /dev/pts: must be superuser` | Некорректная закладка | Удалите строки с `/dev/pts` из `bookmarks` |
| Cron не монтирует диски | Нет переменных окружения для Kerberos в cron | Используйте полный путь к скрипту или `k5start` |

## 7. Заключение
Решение `smb-automount-cifs.sh` обеспечивает безопасное и удобное автоматическое монтирование SMB-дисков в доменной среде ALT Linux. Оно не хранит пароли, создаёт русскоязычные симлинки и закладки, не засоряет интерфейс и легко масштабируется. Рекомендуется для корпоративного использования.
