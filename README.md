# linux-automation

Коллекция скриптов для автоматизации задач системного администрирования на рабочих станциях ALT Linux.

## Состав

- [autoinstall](./autoinstall/) — автоматизация развертывания рабочих станций.
- [cifs-mount](./cifs-mount/) — автоматическое монтирование SMB/CIFS-шар с Kerberos-аутентификацией.
